# main.py
Team Member : Dashawn Hall
New Functions Added:
1	Multiplication: Users can "lock" a number with a key press and multiply it by their current finger count.
2	Squaring (x2): A specialized mode that calculates the square of the fingers shown.
3	Clear History: A specific "fist" gesture (0 fingers) resets the calculation.
4	Mean Calculation: Averages the input if two hands are detected.
5	Power Function (xy): Uses the left hand as the base and the right hand as the exponent.
6	Running Total: Adds current finger counts to a persistent sum.
